独立复核确认 patch/image 各有文件权限及审批路径，**没有据此发现权限旁路**；
“关 shell 后仍可注册”与“未受任何限制”是不同结论。当前缺少的是完整生效工具面
和 A01 边界的实证，不是笼统断言这些原生工具都不安全。

解除条件不是重复审批原 OD-09：命令路线须有可验证的同层隔离能力或环境变化，
再对固定自有进程标记做独立预审后的有限探针；纯文本路线须证明准确的有效工具
和配置闭包，不能依赖提示词；最终认证须在获准的同一环境中有效。当前尚不满足，
不自动换到宽松环境、复制凭证或新开模型会话补证。

已批准的合成生命周期、恢复和固定 Gate 工作可以独立推进。该原生阻塞不应迫使
其他 Worker 或整个研发组织停止，也不应通过重复唤起同一无进展条目消耗预算。

原件保全于仓库外持久目录。公开材料仅含脱敏元数据、安全状态摘要与研究结论；
[清单](FILE-MANIFEST.json) 区分原始和公开哈希。供应商完整源码和原始认证输出
不随本证据提交。此轮没有新的产品测试计数或 provider-live 通过声明。
